**Blocked by:** 01 — Discover a Basic Module Candidate

**Status:** ready-for-agent

- [ ] Support configured namespace patterns for alignment.

- [ ] Support candidate, shared, unassigned, and framework filtering where the output format permits.

- [ ] Add tests for configuration precedence, aliases, namespace patterns, exclusions, and filters.
